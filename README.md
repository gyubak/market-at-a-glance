# 주식 dashboard

[Specification.md](Specification.md) 기준 구현. **1차 슬라이스** + 1차 피드백 반영.

- 백엔드: Python / FastAPI + WebSocket (DB 없음, '오늘' 세션만 메모리)
- 프론트: React + TypeScript + Vite, 캔들은 직접 Canvas 렌더러
- **mock 없음** — 실데이터만. 소스가 끊기면 종가 유지(flat) + 빨간불.

## 데이터

| 영역 | 항목 | 소스 |
|---|---|---|
| 좌측 | NQ=F · WTI · 달러인덱스 · 원달러 (5분봉) | yahoo finance (yfinance 1.2 + curl_cffi) |
| 좌측 | 미국채 2년물 yield (5분봉) | TradingView 소켓 `TVC:US02Y` (비공식) |
| 중앙상단 1행 | 코스피 · 코스닥 (5분봉) | KIS 지수 분봉 / 근월물 코드 넣으면 지수선물(주간F→야간CM 자동) |
| 중앙상단 1행 | 국고채 3년 yield | KIS 금리종합(`HHPST070200C0`, 장내국고채) 5분 누적 |
| 중앙상단 2행 | KOSPI 투자자별(개인/외국인/기관) 누적 순매수 + 기관 세부 | KIS `FHPTJ04030000` 스냅샷 5분 누적 |
| 공통 | 5분봉 push-left, 09:00 시작, **freeze 없음(시간축 계속 흐름)**, 닫힌 시장은 종가 유지, tight 스케일, 노란 배경 크로스헤어(시간 5분 snap / 가격 non-snap), 드래그 좌우 패닝 | |

### 불빛 (종목명 옆 점)

- 🟢 green : 개장 중 + 데이터 수신
- 🔴 red : 개장 중 + 10초 이상 미수신
- ⚫ gray : 폐장 (해당 상품 시장 시간 밖)

## 실행

```bash
# 백엔드
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # KIS 키 입력 (해외는 키 불필요)
uvicorn app.main:app --reload --port 8000

# 프론트 (새 터미널, Node 18+)
cd frontend && npm install && npm run dev   # http://localhost:5173
```

`.env` 설정은 [backend/.env.example](backend/.env.example) 참고.
KIS 토큰은 `backend/.kis_token.json` 에 캐시(분당 1회 발급 제한 회피, 커밋 안 됨).

## 알려진 한계 / 미확정

- **외국인 드릴다운(외국증권사 Top-5)**: "연동 예정" 표시. 회원사 매매동향 TR 은 2차.
- **투자자매매동향 / 국고채 시계열**: KIS 가 스냅샷만 제공 → 서버가 5분 버킷에 누적.
  장 도중에 서버를 켜면 그 시점부터만 쌓임.
- **투자자매매동향 스케일**: `tr_pbmn` 백만원 → 억원(÷`KIS_FLOW_UNIT_DIV`=100) 가정.
- **코스피/코스닥 분봉**: KIS TR 이 한 번에 ~100분치만 반환 → 그 이전 구간은 드래그로 이동 시 비어 있음(페이지네이션 2차).
- **자정 넘김**: '오늘' 기준이라 야간 세션이 자정을 넘기면 익일 재시작 권장.
- **공휴일**: 미반영(주말만 폐장 처리).
- `.env` 의 `DOMESTIC_SOURCE`/`OVERSEAS_SOURCE`/`UST2Y_SOURCE`/`KIS_KTB3Y_CODE` 는 이제 미사용(무시됨).

## 2차 피드백
- 앞서 요청했던 사항들이 잘 지켜진 것으로 확인됨. 
- UI 가시성 향상을 위한 프론트엔드 수정 및 기능에 있어 약간의 디테일을 다듬는 2차 피드백을 아래와 같이 요구함.

### 프론트엔드
1. 가시성
   - 상단바 추가
      - UI 최상단에 상단 5% 정도를 차지하는 상단바를 추가함.
   - 시간 표시 위치 변경
      - 기존에 있던 시간 표시를 상단바 중앙으로 옮김
   - 가격 표시기 추가 및 기존 기능 변경
      - 추가: 상단바 좌측에 좌측 5%에서부터 좌측 30%까지 차지하는 가격 표시기를 추가함. 가격을 표시하고 있지 않을 때도 표시기라는 것을 알 수 있도록 배경 색보다 약간 밝은 진회색 계열로 처리할 수 있을 것임.
      - 기능 변경: 기존에 모든 차트 당 시가/고가/저가/종가를 별개로 표시했던 기능을 없애고 가격 표시기 하나에서 그것을 대신하고 차트마다 공유한다. 공유하는 방식은 마우스 커서를 캔들 차트에 올렸을 때 가격 표시기에 해당 종목의 해당 캔들에 대한 시가/고가/저가/종가를 표시하도록 함. 이 기능 변경의 목적은 이 수치가 개별 종목마다 별개로 존재하니 궁금하지 않은 상태에에도 기본적으로 UI를 차지하고 있어 공간에 비효율적이고 어지러워 보임. 가격을 자세하게 알고 싶을 때는 사람들은 마우스 커서를 올려서 확인하고자 한다는 점에서 착안했고 이를 통해 공간 효율적이고 정돈된 UI를 기대할 수 있음. 단 마우스 커서를 캔들 위에 올리지 않은 경우에는 상단바 좌측 가격 표시기에 아무것도 송출하지 않도록 함. 반면 차트에서 시가/고가/저가/종가는 삭제하되 현재 가격(또는 수치)은 기존과 같이 유지하고 지금처럼 표시해야 함.
   - 글자 크기
      - 모든 글자, 숫자들에 대해서 글꼴 크기를 약 50% 정도 키웠으면 좋겠음.
   - 시간축 데이터
      - 현재에는 시간 축으로 정각에는 00:00 형식으로, 이외에는 15, 30, 45로 표시하고 있으나 그냥 정각 00:00에 대해서만 표시하도록 함. 다시 말해 15, 30, 45 분 레이블을 표시했던 것을 없애줘.
   - 해외 데이터 UI
      - NQ=F
         - '나스닥 선물'로 이름 변경
         - 현재 선물 수치를 표시하는 곳 좌측에 +-0.00%와 같은 등락률을 표시할 것.
      - US 2Y yield
         - '미국채 2년'으로 이름 변경
      - WTI crude
         - 'WTI'로 이름 변경
      - Dollar Index
         - '달러 인덱스'로 이름 변경
   - 국내 데이터 UI
      - 코스피/코스닥 주야간 선물 데이터에 현재 선물 수치를 표시하는 곳 좌측에 +-0.00%와 같은 등락률을 표시할 것.

### 백엔드
1. 시간축 문제
   - NQ=F, WTI, Dollar Index에 대하여, 현재 시점의 데이터가 10분 전 봉에 업데이트가 되고 있음. 반면 5분전 봉과 현재의 봉 자리에는 시가/저가/고가/종가가 같은 마치 데이터가 없는 것처럼 보이는 캔들로 표시되는 문제가 있음.
2. 업데이트 주기
   - KSI의 업데이트 속도는 5-10초 정도의 딜레이로 사용하기에 문제가 없어 보임. 반면 yahoo 데이터를 약간 더 빠르게 가져올 수 있으면 좋겠음(현재 딜레이보다 약 20%-50% 더 자주 데이터를 가져왔으면 좋겠음).
### 2차 피드백 반영 결과

**프론트엔드**
- 상단바(≈5%) 추가. 시계는 상단바 중앙 `HH:MM:SS KST`.
- 가격 표시기: 상단바 좌측(4~34%), 배경보다 밝은 진회색 박스. 평소 비어 있음.
  캔들 차트에 마우스를 올리면 그 종목·그 봉의 시/고/저/종을 표시(모든 차트 공유). 커서를 떼면 지움.
- 차트 헤더에서 시/고/저/종 제거. 현재가(노란 태그 + 점선)는 그대로 유지.
- 등락률(전일 대비 %): 나스닥 선물 / 코스피·코스닥 선물 헤더 우측에 표시.
  - 나스닥 = yahoo `fast_info.previousClose` 대비, 코스피·코스닥 = KIS `futs_prdy_ctrt`.
- 글꼴 전체 약 +50% (12→18px 기준).
- 시간축: 정각(`HH:00`)만 라벨. 15/30/45분 라벨 제거(눈금선은 옅게 유지).
- 라벨 변경: 나스닥 선물 / 미국채 2년 / WTI / 달러 인덱스.

**백엔드**
- 시간축 문제 해결: 개장 중인 시계열은 flat 패딩을 하지 않음(지연된 야후 봉을 가짜 봉으로 덮지 않음).
  대신 `fast_info.lastPrice` 로 현재 5분 봉을 갱신 → 현재가가 최신 유지. flat 패딩은 폐장 상태에서만.
- yahoo 폴링 10s → 6s (`POLL_YAHOO_SEC`). TradingView·KIS 는 기존 유지.

## 3차 요청사항
### 프론트엔드
- 글꼴 크기가 기대했던 것보다 너무 커진 것 같다. 모든 글꼴을 약 35% 정도 작게 해줄 수 있니? (단, 상단바의 시계 글꼴은 글꼴을 작게하지 말고 현재를 유지할 것)
- 가격 표시기의 세로폭(박스의 높이)을 지금의 85% 수준으로 해줬으면 좋겠어
- 각 종목 별 현재 가격(또는 수치)는 원래 자리(해당 블록 안에서 종목명의 반대편)에 표시했으면 좋겠어.
- 나스닥 선물, 국내 지수 선물에서 +-0.00% 등락률은 그 종목의 현재 가격(또는 수치) 좌측 부분에 표시했으면 좋겠어
### 3차 요청사항 반영 결과
- 글꼴: body 15px, 상단바 시계 20px, 캔버스/축 12px.
  가격 표시기 안 텍스트는 가독성 때문에 10~11px 로만 축소.
- 가격 표시기 박스 높이를 이전의 85% 수준으로 축소 (`height: calc(85% - 6px)`).
- 각 종목 현재가(또는 수치)를 블록 헤더 우측(종목명 반대편)에 복원.
- 등락률(±%)은 그 현재가의 **좌측**에 표시 (나스닥 선물·코스피/코스닥 선물).
- 패널 높이도 함께 축소(좌측 165 / 중앙상단 150).

## 5차 요청사항
- 이건 프론트엔드인지 백엔드인지 모르겠다. 나스닥선물/WTI/달러인덱스 데이터를 확인해봤는데 현재 시간으로부터 5분 전 봉(바로 옆에 봉)이 데이터가 비어있다. 그 과거 데이터들은 다 있는데 현재 기준으로 바로 옆봉만 데이터가 나스닥선물/WTI/달러인덱스에 대해서 동일한 문제가 발생하였다. 확인해줄 수 있니?
### 5차 요청사항 반영 결과
- 나스닥 선물/WTI/달러 인덱스에서 '현재 봉 바로 옆(5분 전) 봉'이 비던 문제 수정.
  원인: yahoo 5분봉이 ~10분 지연 → 마지막 실봉과 `fast_info.lastPrice` 로 만든 현재 봉 사이에 5분 버킷 1개가 빔.
  수정: `CandleStore.fill_to_now()` 가 **실제 봉 사이의 빈 5분 버킷을 직전 종가로 항상 flat 채움**
  (지연분은 다음 폴링에서 실데이터로 덮임). TradingView(미국채 2년)의 듬성한 봉도 함께 메워짐.

### 6차 대응 결과 (해외 데이터 실시간화)
- 나스닥 선물 / WTI / 달러 인덱스 / 미국채 2년 → **TradingView 스트리밍**으로 전환(실시간에 가까움).
  - 하나의 상시 websocket 연결로 4심볼 구독(심볼마다 chart 세션, 게스트 제한 회피).
    스냅샷 폴링이 아니라 스트리밍이라 **차단 위험이 낮고** 더 실시간.
  - 심볼: 나스닥=`OANDA:NAS100USD`(24h CFD — `TVC:NDX` 지수는 야간이 비어서), WTI=`TVC:USOIL`,
    DXY=`TVC:DXY`, 미국채2년=`TVC:US02Y`. `.env` 의 `SOURCE_*` / `TV_SYMBOL_*` 로 조정.
  - 원달러는 yahoo `KRW=X` 유지(FX는 원래 거의 실시간).
- **자정 넘김 지원**: 세션 기준을 "가장 최근 09:00 KST"로 바꿈(`market.day_open`).

   -> 확인 완료
- **폰트 반응형화**: 레이아웃(`--panel-w` 등)은 이미 `vw` 기반이라 화면 폭에 비례하는데 글자 크기는 고정 px였음.

- **09:10 재기동 시 데이터 누락 원인**: 하드코딩된 09:00~15:30 캐시는 없었음(KIS 조회 파라미터는 항상
  현재 시각 기준으로 매번 새로 계산됨). 실제 원인은 `CandleStore`가 국내/해외 구분 없이 모든 종목을
  `day_open()`(직전 09:00 KST) 기준으로 잘라서 보관하고 있었던 것 — 코스피/코스닥처럼 09:00에 개장하는

  → `CandleStore`에 `market_key`를 넘겨서 `global`은 09:00 컷 대신 최근 36시간 롤링 윈도우를 쓰도록 수정.

### 9-1차: 코멘트 반영 결과
- **폰트 크기 +15%**: `--fs-*` clamp 변수들의 최소/vw/최대값을 모두 15%씩 상향(예: 차트 헤더 11px→13px, 시계 20px→23px). 13인치 하한이 커진 만큼 27인치 이상에서의 비례 확대분도 같이 커짐.
- **해외 차트가 여전히 09시부터 나오던 이유**: 9차 수정은 `CandleStore` 내부 경계만 고쳤는데, 그 앞단에 데이터가 들어오기도 전에 09:00 이전을 잘라내는 별도 필터가 두 곳 더 있었음(수정이 무의미했던 원인).
  - [yahoo.py `_fetch()`](backend/app/sources/yahoo.py#L45-L70): yfinance에서 받은 봉을 CandleStore에 넣기도 전에 `if dt < day_open(...): continue`로 걸러내고 있었음 → 제거. 아울러 36시간 롤링 윈도우를 다 채울 수 있도록 조회 기간도 `period="1d"` → `"2d"`로 늘림.
  - [tradingview.py `_bucket()`](backend/app/sources/tradingview.py#L61-L66): TV 소켓에서 받은 봉도 동일하게 09:00 이전이면 `None`을 반환해 버리고 있었음 → 제거하고 `CandleStore`가 알아서 윈도우를 적용하도록 변경.
  → 나스닥 선물·WTI·달러인덱스·미국채2년·원달러 전부 이제 실제로 36시간 전 데이터까지 표시됨.
- **코스피 선물이 08:45가 아니라 09:00부터 표시되던 이유**: `day_open()`이 국내 상품은 전부 09:00 하나로 고정돼 있었음. [market.py](backend/app/market.py)에 `KR_FUT_OPEN=(8,45)`를 추가해 `kr_futures`는 08:45, `kr_regular`는 09:00을 쓰도록 분기.
  다만 [series.py](backend/app/series.py#L26-L27)에 정의된 `kospi_fut`/`kosdaq_fut`의 기본 `market_key`가 애초에 `"kr_regular"`였어서(런타임에 KIS 선물 코드가 잡혔을 때만 `"kr_futures"`로 바뀌고, `CandleStore`는 그 이전의 기본값으로 이미 만들어져 있었음) 이 분기를 타지도 못하고 있었음 — 기본값 자체를 `"kr_futures"`로 바꿔서 실제 사용 케이스(선물 코드 설정됨)에 맞춤.
  → 코스피/코스닥 선물이 08:45부터 표시됨.

### 9-2차: 차트 가로/세로축 폰트 반응형화
- 헤더(종목명/등락률/가격)와 달리 차트의 가로/세로축 눈금, 크로스헤어 태그, 현재가 노란 박스는 canvas에

  draw effect에서 `getComputedStyle`로 그 값을 읽어 `ctx.font`에 매 렌더마다 반영(색상을 `--up`/`--muted` 등에서

## 10차: 코스피 히트맵 + 거래대금 상위종목

Specification.md 2.1.2 종목 정보 파트(히트맵/거래대금 상위/검색 상위) 구현. 착수 전 KIS API 문서를 실측
확인한 결과 스펙 문서의 가정과 다른 점이 있어 아래 3가지를 먼저 정하고 진행함(사용자 확인 완료):
1. 히트맵은 **섹터별 트리맵까지** 구현(목록 폴백이 아니라 스펙 원안대로).
2. **검색 상위종목**: KIS Open API엔 실시간 검색순위/조회수 순위 TR이 아예 없음(순위분석 카테고리
   전체를 뒤져 확인). 가장 가까운 "관심종목등록 상위"도 결이 달라 1차에서는 스킵하고 거래대금 상위만 구현.
3. 상위 종목 개수는 **30개**로 시작(KIS 랭킹 TR 3종 전부 "최대 30건, 다음 조회 불가"가 공식 문서에 명시돼
   있어서 — 50개를 채우려면 HTS에 조건을 미리 등록해야 하는 종목조건검색 API라는 별도 트랙이 필요).

### 백엔드 — [kis_rank.py](backend/app/sources/kis_rank.py)
- **시가총액 상위 30**(`FHPST01740000`) → 히트맵. **거래대금 상위 30**(거래량순위 `FHPST01710000`을
  `FID_BLNG_CLS_CODE=3`으로 조회) → 우측 패널 리스트. 이미 hub의 pub/sub 구조(`kind` 태그 기반)를 그대로
  써서 `kospi_heatmap`/`value_rank`라는 새 시계열 id로 발행.
- **섹터 그룹핑**: 랭킹 응답엔 업종코드가 없어서 종목별 주식기본조회(`CTPF1002R`)를 추가 호출해야 함.
  실측해보니 `idx_bztp_lcls_cd_name`(대분류) 필드는 이름과 달리 실제로는 "시가총액규모대/중/소"(사이즈
  등급)를 반환하고 있었고, 진짜 업종(전기전자/운수장비/금융업 등)은 `idx_bztp_mcls_cd_name`(중분류)에
  있었음 — 문서 설명만 믿었으면 "대형주"/"중형주"로 묶이는 완전히 엉뚱한 히트맵이 나올 뻔함. 업종은
  거의 안 바뀌므로 종목코드별로 한 번만 조회 후 캐시(실패한 조회는 캐시 안 하고 다음 폴링에 재시도).
- **스파크라인**: 종목별 분봉 TR을 또 부르는 대신, 20초 폴링 자체가 찍는 가격을 종목코드별로 누적(최근
  60개)해서 만듦 — 추가 API 호출 없음.
- 시가총액(`stck_avls`)은 실측 결과 이미 억원 단위, 거래대금(`acml_tr_pbmn`)은 원 단위라 `/1e8`로 변환.

## 10차 요청사항
1. 코스피 히트맵 패널
- 종목이 0.0%로 보합인 경우 회색으로 표현
- 종목 및 등락률, 섹터 표기의 글꼴이 너무 작음 이것도 해상도 및 히트맵 크기에 감응형으로 동작했으면 좋겠음
2. 거래대금 및 검색상위 패널
- 각 종목 박스 크기의 세로 길이가 너무 작음
- 선차트랑 현재가, 등락률이 겹쳐서 출력됨
- 현재가와 등락률의 글꼴이 너무 낮음. 그리고 좌측과 상단의 다른 차트처럼 +0.00% 1,000,000 이런 식으로 표시했으면 좋겠고 등락률은 상승 하락에 맞는 색깔로, 현재가는 흰색으로 해줘.
- 아무 데이터가 없을 때 빨간색 가로선이 선차트로 표시되는 것 같은데 보기에 좋지 않음
### 10차 대응 결과
1. 히트맵
   - 보합(|등락률| < 0.05%)이면 회색(`--heat-flat`)으로 표시.
   - 종목명/등락률/섹터명 폰트를 셀·섹터 크기에 비례하도록 JS에서 계산(→ 해상도·패널 크기 모두 감응).
     너무 작은 셀은 텍스트 숨김, 조금 작으면 이름만.
2. 우측 종목 리스트
   - 행 높이 `clamp(58px, 4.6vw, 92px)`로 확대.
   - 현재가/등락률(윗줄)과 선차트(아랫줄)를 세로로 분리 → 겹침 해소.
   - 좌측 캔들 헤더와 동일 포맷: `+0.00% 1,000,000` (등락률 = 상승/하락 색, 현재가 = 흰색), 폰트 반응형.
   - Sparkline: 점 3개 미만이거나 값 변동이 없으면 아무것도 안 그림(빨간 가로선 제거).
